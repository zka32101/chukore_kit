# ちゅうコレ！のコンセプト整理

> 2026-11-01 時点の整理。判断の根拠は各文書にリンクする。方針の一覧は [`design_principles.md`](design_principles.md)。

## 1. 一言
**「気づいたら、点が上がっている。」** 頑張って使うアプリではなく、毎日ちょっとで伸びが見えるアプリ。中学生の定期テスト・受験の対策に絞る。

## 2. 誰の、何のためか
- 対象は**中学生だけ**（小学コレ！とは別の基盤）。目的は**テスト日から逆算した対策**。テスト日のない習慣モードは作らない。
- **教科ごとに別アプリ**（英語 → 数学 → 社会 → 理科 → 国語）。入口は弱い 1 教科。2 教科目からセット。国ごと・教科ごとにリポジトリを分け、共通の部品がこの `chukore_kit`。
- 日本から始め、10 カ国以上を想定。国・言語は**データ**（`RegionProfile`・`CurriculumPack`・文言）で切り替え、コードに国名の分岐を書かない。

## 3. 三つの約束
1. **責めない**: まちがいは「どこがちがうか」だけを返す。点・順位・ライフ・時間制限の課金はなし。
2. **子どもに安全**: 広告なし、同意なし・トラッキングなしが既定。基盤はデータを集めず、送らない。法務確認が要る機能は確認まで止める。
3. **わかる**: 教科書のような説明を、**現実の具体例**と**図・動く図**で。「覚える」前に「なるほど」を作る。

## 4. 学びの流れ
診断（つまずきの型）→ 前提の単元へさかのぼる → 説明（レッスン: 導入の場面・例題・確認）→ 練習（型から無限に変種を出す）→ 単元テスト → 復習（間隔反復）→ テスト後の振り返り。計画・診断は手段で、前面には出さない。

## 5. 基盤が持つもの（教科共通 / 教科ごと）
| 層 | 内容 |
|---|---|
| 共通 | 単元ツリーと前提、出題の計画と復習、単元テスト、遊びの周回（`PlayRound`）、分析、体験（並べ替え・結ぶ・ダイヤル・天秤・年表）、場面、文言（`texts.json`）、コンテンツパックの一括検証 |
| 数学 | 問題の型（変種の自動生成・誤答の型）、図（点・線・立体・グラフ・動く図）、作図、探究、証明（並べる・根拠を選ぶ） |
| 社会 | 地図（`MapPack`）、グラフ（`ChartSpec`）、年表、時差、地図タップ |
| 英語 | 語順の並べ替え・穴埋め・単語の間隔反復（音声・自由記述の採点には頼らない） |

## 6. コンテンツの作り方
- 内容は**パック**（`manifest.json`＋単元・型・レッスン・場面・証明・文言…）。`dart run tool/validate_pack.dart` が、参照切れ・未使用・文言の欠けを機械的に見つける。詳細は [`content_pack_spec.md`](content_pack_spec.md)。
- 文言は ID で分け、言語ごとに差し替える（日本語で正しく読める＝全変種で `{}` が残らない、解説が答えを含む、をテストで固定）。
- 草案は**教育者の確認前**。教科書・指導要領との照合、国土地理院などの利用条件、18 言語のネイティブ確認は未了。

## 7. 今できていること / これから
- できた（草案）: 数学 中1（型 91・レッスン・文言）、中2（型 32・証明 4）、中3（型 30・証明 2・場面・動く図）、社会 中1（単元・前提・問題・グラフ）。
- これから: 社会 中1 の説明文と動く図（雨温図の月送り・時差の昼夜）、数学の残り（式の利用・証明の追加・立体の切断）、英語の問題の増量（現在 16 問）、理科・国語の基盤、実写・動画の方針（要確認）、教育者のレビュー、ソフトローンチの検証（[`softlaunch_validation_plan.md`](softlaunch_validation_plan.md)）。

## 8. 数学に取り込んだ案（コンセプトから）
「気づいたら、点が上がっている。」を数学に落とすと、**ケアレスミスが減り、「なるほど」が増える**こと。次を取り込んだ。
- **検算の習慣**: 一次方程式の解を代入して確かめる型（`m1_linear_check_001`）。
- **先に符号を決める**: 積の符号を、計算の前に決める型（`m1_num_mul_sign_001`）。答えの見当にも検算にもなる。
- **見た目でわかる**: 立体の切断を、身近なもの（ロールケーキ・コーン・みかん・サイコロ）の切り口の形と、角を切り落としたときの面・頂点・辺の数で（`m1_space_cut_*` の 8 型）。数え上げは、頂点 - 辺 + 面 = 2 に気づく入口にもなる。
- **証明は「穴埋め」から**: 並べる・根拠を選ぶ遊びで、白紙から書かせない（責めない）。
- 取り込まなかった案: 連続日数・ランキング・時間制限（約束に反する）、実写・動画（方針の確認待ち）。
