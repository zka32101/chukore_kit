# 海外展開の基準: 国ごとに人気の1教科から、伸びたら2教科目

> ステータス: 基準の案（数値は暫定）。**結果を見てから基準を動かさない**ため、出す前にここへ決めて記録する。値の変更は1回ずつ、変えた日と理由を「変更履歴」に残す。

## 1. 進め方

1. 国ごとに、**現地で人気の教科を1つだけ**出す（選び方は §2）。
2. 一定期間見て、§4 の基準を満たしたら**2教科目**を出す。満たさなければ §5 の判断。
3. 毎回の結果を §6 の記録表に残す。次の国の判断材料にする。

同時に進める国は最大2つ（新シリーズ計画 v0.14 の「同時進行は最大2シリーズ」に合わせる）。

## 2. 最初の1教科の選び方

材料は**ストア側の画面**（かずきさんが確認）で集める。推測で決めない。

| 材料 | 見るもの |
|---|---|
| 需要 | 現地ストアの教育カテゴリ上位・検索語（「matemática 6º ano」など）に出る教科の偏り |
| 競合の薄さ | その教科の上位アプリの評価件数・価格（無料の強豪がいない教科を選ぶ） |
| 出しやすさ | 数学・理科はそのまま出しやすい。社会・国語は国ごとの作り直しが必要なので後回し |
| 現地カリキュラムとの対応 | `CurriculumPack.validate()` が問題なしになる（網羅すべき項目が埋まる） |

- 需要が拮抗したら、出しやすい教科（数学 → 理科）を選ぶ。
- 候補（暫定、ストアの確認前）: ブラジル＝数学、インドネシア＝数学。
- 日本は決定済み（英語 → 数学 → 社会 → 理科 → 国語）で、この表の対象外。

## 3. 出す前の条件（国ごと）

- [ ] `RegionProfile` に、その国の法務確認の結果を入れた（年齢・保護者同意・広告・課金手段・保持日数）
- [ ] `CurriculumPack` が `validate()` で問題なし（現地の教育者の確認つき）
- [ ] 文言のネイティブ確認が済んだ（`native_review_checklist.md`）
- [ ] 価格を現地化した（無料サンプルの量も決めた）
- [ ] 実機で文字拡大 200%・RTL（該当言語）・色覚を確認した

## 4. 2教科目に進む基準（案）

見る期間は、公開から**8週間**（暫定）。全部ではなく、**必須3つを満たし**、補助のうち1つ以上を満たしたら進める。

| 区分 | 指標 | 基準（暫定） | 出どころ |
|---|---|---|---|
| 必須 | 初回で3問正解まで届いた割合（Aha） | 60% 以上 | 小学コレの基準を流用 |
| 必須 | 7日後の継続 | 35% 以上 | 小学コレの基準を流用 |
| 必須 | 30日後の継続 | 15% 以上 | 小学コレの基準を流用 |
| 補助 | 無料から有料への転換 | 現地価格で 3% 以上（日本の目標 5% を現地の購買力で下げた仮値） | 要見直し |
| 補助 | ストア評価 | 4.0 以上（評価件数 50 件以上） | |
| 補助 | 同じ国の別教科への問い合わせ・レビュー要望 | 複数件 | |

- 件数が少なすぎる間は判断しない（目安: 初回起動 500 人以上）。
- 継続の数字は、`tool/quality_report.dart` や `analyzeRelapses` ではなく、アプリ側の分析基盤（匿名・集計のみ）で見る。基盤は集めない。

## 5. 基準を満たさないとき

| 状況 | 判断 |
|---|---|
| Aha が低い | 最初の1問・言語・難易度を直す。2教科目は出さない |
| 継続が低い | 復習間隔・通知・先生役の文面を見直す（現地話者の確認） |
| 継続は高いが転換が低い | 価格・無料サンプルの量を見直す |
| 需要そのものが薄い | 別の教科に差し替えるか、その国は止める。止める基準も先に決めておく（下記） |

**止める基準（暫定）**: 8週間を2回（計16週）続けて必須3つのうち2つ以上を満たさなければ、その国は一時停止。
