# 数学のパックを国別に差し替える設計

> ステータス: 設計＋最初の部品を実装（2026-11-02）。国の最初の教科は数学（[`country_priority.md`](country_priority.md) §7）。数学の内容を、**国ごとに作り直す部分**と**国をまたいで使い回す部分**に分ける。

## 1. 層
| 層 | 中身 | 国をまたいで | 国ごと |
|---|---|---|---|
| 核（言語に依存しない） | 問題の型（変種の作り方・式・誤答の型）、図の仕様（点・線・グラフ・動く図）、作図・探究・体験の仕様、証明の構造（行と根拠のつながり）、検算 | 使い回す | — |
| 国の層 | 単元ツリーと前提（その国のカリキュラム）、どの型をどの単元に置くか、**文言（`texts.json`）**、レッスン、場面（その国の暮らしの例）、キャラの文言、順序 | — | 国ごとに作る |
- 数式・図・数字は言語に依存しない。**作り直しの中心は文言と単元の並び**。

## 2. 言語に依存していたもの（洗い出し）と対応
| 場所 | 以前 | 対応 |
|---|---|---|
| 問題文・解説・図の説明・レッスン | `texts.json`（国・言語ごと） | もともと分離済み |
| **選択肢の文言**（図形の名前、通貨つきの式、操作の説明） | `templates.json` に日本語が直接 | **`choiceLabels`**（実装済み）: 選択肢は ID（`circle` など）。文言は `texts.json` の `choice_<型ID>_<選択肢ID>`（`{…}` で値を差し込める）。国・言語ごとに差し替え。検証が、直接書かれた文字を警告（`template_choice_locale_text`）し、文言の欠けをエラーにする |
| 型の `display` の文字（`cut` など） | 画面に出さない記号 | 問題なし |
| 数式・単位（cm、°、π、√） | 国際的な記号 | そのまま |
| 通貨（円） | 問題文・選択肢の文言 | 文言側（通貨の記号と値の大きさは国ごとに差し替える。場面の値は `plausible` で現実の範囲を保つ） |
| 単元の ID（`m1_…`） | 日本のカリキュラム | 国の層（下の「型の置き場」） |

## 3. 国の層の作り方（手順）
1. **核の型を選ぶ**: その国のカリキュラムの項目ごとに、使える型を選ぶ（日本の中1〜中3の 162 型を出発点にして、無い項目は新しく作る）。
2. **単元ツリーと前提を作る**（その国の学年・単元・用語）。型の `unitId` を、その国の単元に付け替える（現状は型にユニットが書かれているので、**国ごとに `templates.json` をコピーして `unitId` を書き換える**。将来は「型の置き場」の対応表で分ける）。
3. **文言を翻訳・現地化する**（`texts.json`: 問題文・解説・図の説明・選択肢・レッスン・場面）。数字や式は変えない。現地の暮らしの例（通貨・食べ物・スポーツ）に置き換える。
4. **目録（`manifest.json`）**: `country`・`locale`・`curriculum`・`contentVersion`。`dart run tool/validate_pack.dart` が、参照切れ・文言の欠け・数字の矛盾を見つける。
5. **検算**（`test/answer_oracle_test.dart`）: 問題文の数字から答えを解き直す。**言語が変わると問題文から数字を拾う作りが合わなくなる**ので、国の層の検算は、その国の問題文に合わせて書く（または、問題文でなく**変種の値**から検算する形に広げる。次の作業）。
6. ネイティブの確認（`native_review_checklist.md`）と、現地の教育者の確認。

## 4. 国の層で気をつけること
- カリキュラムの順番が違う（例: 連立方程式を何年で習うか、確率の導入）。型は変えずに、単元への置き方を変える。
- 記数法・小数点（`.` と `,`）、数字の書き方（アラビア文字・デーヴァナーガリー数字）は、画面側（`ChukoreStrings` と数字の表示）。式の入力は `decimalSeparator` を渡せる。
- 右から左に書く言語（アラビア語）は、数式は左から右のまま。文言だけ RTL。
- 図の中の文字（点の名前 A・B・C）は、国によってラベルが違う（例: 英語圏は ABC、日本は ABC、ロシアはキリル文字）。図の `names` のラベルを国ごとに指定できるようにするのが課題。

## 5. まだ決めていない・やっていないこと
- **型の置き場**: 核の型と、国ごとの「単元への置き方」（`placement.json`: 型ID → 単元ID と順序）を分ける。現状は型に `unitId` が入っている。
- 検算を、問題文でなく変種の値から行う形に広げる（言語に依存しない検算）。
- 図の点の名前（ラベル）を国ごとに変える。
- 日本以外の最初の国（ブラジル・インドネシア）の、カリキュラム対応表の作成。
