# ちゅうコレ！の世界観（基地から旅に出て、仲間の部屋を訪ねる）

> ステータス: 方針を決定（2026-11-02 運営者）。**絵のトーンは未決定**（§6）。キャラの仕組みは [`character_design.md`](character_design.md)、分野分けは [`field_division.md`](field_division.md)。

## 1. 一言
**自分の基地から旅に出て、分野をマスターして、仲間の部屋に入る。** 勉強した分だけ、相棒が育ち、基地がにぎやかになり、世界が広がる。

## 2. 基地（ホーム）
- 自分の居場所。**相棒**（教科ごとに 1 匹・成長する）が住む。
- 図鑑（ゲットした分野キャラ）、スタンプ、バッジ、振り返り（点の変化・成長カード）を置く。
- 相棒が成長すると、基地の家具や景色が増える（成長に応じて決まるものだけ。課金・運・順位なし）。

## 3. 旅と部屋
- 教科ごとに「地図」がある。**分野が 1 つの土地**（数学は 22、全教科で 79）。
- 土地には、その分野のキャラの**部屋**がある。
  - **ゲット前は見えない**（運営者の決定）。部屋への道と「あと N 単元」だけが見える。
  - **分野をマスターしてゲットしたら、部屋に入れる**。マスターすれば必ず入れる（運・課金・順位なし）。
- **部屋は学年で分ける**。中1・中2・中3 のそれぞれに「建物」があり、その階が分野の部屋。学年が上がるほど、高い場所・広い景色に（成長と同じ向き）。
- **世界は教科や分野のイメージに合わせて分ける**（§4）。

## 4. 教科の世界（案）
| 教科 | 世界のイメージ | 部屋の雰囲気の例 |
|---|---|---|
| 数学 | 工房・設計室（ものをつくる・測る・組み立てる） | 図面、定規、模型、建築 |
| 英語 | 港・空港（世界とつながる） | 搭乗口、手紙、世界地図、航路 |
| 社会 | 地図と街並み（世界を旅する・時間をさかのぼる） | 駅、博物館、古い地図、広場 |
| 理科 | 研究所と自然のフィールド（観察・実験） | 実験台、森、星空、天気図 |
| 国語 | 図書館・言葉の庭（読む・書く・伝える） | 書棚、万年筆、手紙、庭の本 |
- 地域キャラ（その国らしいキャラ）は、その国の土地の住人。国ごとに、土地の名前・景色の一部を差し替える。

## 5. 部屋の中身（優先順位）
1. **実例・中学生の身の回りに関係する小ネタ**（運営者の決定）: 部活、スマホ、お金、SNS、天気、スポーツなど。教科の「なるほど」を、中学生の生活とつなげる。
2. キャラのひとこと（3 つ程度）。
3. スタンプの保存（8 枚。`character_design.md` §3.5）。
4. 教養（数学者の話、世界の実例）は、その次。
- 約束: 順位・比較・煽りの言葉なし。ひとことは責めない。個人の情報は出さない。

## 6. 絵のトーン（未決定。小学コレ！は「かわいい」）
中学生は「かわいい」だけだと幼く感じる子がいる。3 案:
| 案 | 内容 | 良い点 | 心配 |
|---|---|---|---|
| A かわいい | 小学コレ！と同じ | 安心感、シリーズの統一 | 中学生が恥ずかしい・幼い |
| B ゆるかわ（落ち着いた） | 線がシンプル、くすんだ色、小さめキャラ、余白 | 友だちに見せても恥ずかしくない。かわいさも残る | 絵のルールづくりが要る |
| C クール寄り | しっかりした画風、動物でも少しリアル | 大人っぽい | 絵のコストが大きい。冷たく見えることも |
- 推し: **B を基本に、学年で少しずつ大人っぽく**（中1 はゆるかわ→中3 はすっきり）。キャラの成長・世界が高く広がる向きと合う。
- 決める方法: 同じキャラを A・B・C で 3 枚描いた見本を、中学生の保護者・本人（可能なら）に見てもらう。

## 7. 部品とのつながり
基地・相棒・図鑑・スタンプは `character_design.md` の部品（`CompanionProgress`・`zukan`・`stickersEarned`）。部屋と地図（土地・建物・階）は、まだ部品がない（絵とセリフの量を見て仕様を作る）。部屋の小ネタは文言の ID（`texts.json`）で、国・言語ごとに差し替える。

## 8. 決めること
- 絵のトーン（§6）。
- 部屋の量（79 部屋）の絵の作り方: 教科ごとに共通の背景＋キャラ別の小物 3 つ程度にして量を抑える案。
- 部屋の小ネタの書き手（実例のチェックをする人）。国ごとの身の回りの違い（部活・通学・お金の使い方）をどう反映するか。
