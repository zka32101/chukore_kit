# 最初の教科の再確認（日本）: 英語でよいか

> ステータス: 2026-10-28 の再調査。**ストアの詳細ページ・公的調査の原典・検索量は取れなかった項目が多い**（「未取得」は作っていない）。結論は暫定。決定済みの発売順（英語 → 数学 → 社会 → 理科 → 国語。企画設計書 v0.7 §7）を、見直す材料があるかを確かめた。

## 1. 結論

**英語を最初にする判断は、維持してよい（根拠は中程度）。** 需要は数学のほうが大きいが、競合の強さと作りやすさで英語が有利。ただし、**同価格帯の直接競合が既にある**ので、価格ではなく設計で差をつける前提にする。

## 2. 比べた結果

| 観点 | 英語 | 数学 |
|---|---|---|
| 需要（苦手の多さ） | 2〜3位（約16%） | **1位（35〜41%）** |
| 競合の強さ | 直接競合は小規模（StudyPeaks 評価 4.3・399件）。動画型（スタディサプリ）と通信教育は別の価格帯 | **最も強い**: QANDA（評価約2.8万件・写真で解く）、スタディサプリ（約1.9万件）、Photomath、すらら（さかのぼり）、中学ポピー（テスト日登録） |
| 「逆算」「さかのぼり」の希少性 | 英語アプリでは確認できず（確認範囲） | **すらら・中学ポピーが既に打ち出している** |
| 同価格帯の直接競合 | **あり**: 中学英語（StudyPeaks）が通常 300円/月で定期テスト対策を明記。無料版は広告あり | 数学単体で同価格帯の定期テスト対策アプリは確認できず |
| 作りやすさ | 選択・並べ替え・穴埋め・短い記述で文法と語彙を扱える（基盤の問題タイプで足りる）。音声・自由記述の採点は避ける | 数式入力（分数・累乗・平方根）、途中式の採点、図形・作図が難所 |
| 診断（誤解の型） | 英文法は型が有限で作りやすい（三単現、be動詞と一般動詞の混同、語順など） | 型は作れるが、入力と採点の難しさが先に来る |
| 間隔反復との相性 | **強い**: 語彙が 1,600〜1,800 語に増加（新学習指導要領）。覚える→忘れる→思い出すの繰り返しが「気づいたら」に効く | 計算の反復には効くが、語彙ほど顕著ではない |
| 海外への持ち出し | 日本人向けの英語は、海外では別の商品になる | **そのまま出しやすい**（ブラジルなど） |

## 3. 英語を最初にする条件

1. **範囲を絞る**: 文法・語彙・語順・穴埋めの選択式と短い記述。**スピーキング・発音・自由英作文は入れない**。
2. **価格で戦わない**: StudyPeaks と同じ 300円帯。差は「テスト日からの逆算」「つまずきの型の診断と前提へのさかのぼり」「責めない」**「広告なし」**（相手の無料版は広告あり）。コンセプト「気づいたら、点が上がっている。」を、語彙の間隔反復と、文法の誤解の診断で形にする。
3. **動画ではないことを明示**: 演習特化。動画（スタディサプリ・Try IT）の代わりではなく、補完。
4. **数学は2番目のまま**: 写真系が強い教科なので、診断と計画の差が効くかを、英語の結果を見てから判断する。海外（ブラジル）に持ち出す教科でもあるので、数式入力と検証（CAS）の準備は並行して進める。

## 4. 確かめきれていないこと（決定を覆しうるもの）

| 未確認 | 確かめ方 | 結果で変わること |
|---|---|---|
| StudyPeaks のレビュー本文（不満の傾向） | ストア画面で 1〜2 星を分類 | 不満が「広告」「内容の浅さ」なら差別化が効く。「十分に良い」なら、英語の優位が下がる |
| 教科別の需要の原典（ベネッセ学習基本調査、国研）、検索量 | 原典の確認、キーワードプランナー | 英語の需要が想定より小さければ、数学を前倒しする根拠になる |
| 教科別の保護者の支払い意思・塾/通信/アプリの利用率 | 同上（未取得） | 同上 |
| スタディサプリの公式価格、Quizlet、教科書準拠アプリ、Khan Academy、Atama+ | ストア画面・公式 | 競合の地図の補強 |
| 英検・高校入試での英語の比重、リスニング配点 | 都道府県の入試要項 | 音声を後回しにしてよいかの判断 |

## 5. 見直しの条件（先に決めておく）

ソフトローンチ（日本）で、`docs/global_rollout_criteria.md` の必須 3 指標（Aha 60%・7 日継続 35%・30 日継続 15%）を満たさず、かつ上の未確認の調査で英語の需要の弱さが確かめられたら、数学を前倒しする。基準は結果を見る前に決めて、そのまま使う。
