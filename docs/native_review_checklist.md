# ネイティブ確認チェックリスト

各言語の文言は、機械的な訳のまま出さないために、**出す言語ごとにネイティブの人が確認する**。このファイルは、確認を頼むときの依頼書として使う。

## 進め方
1. 文言の一覧は [`translation_review.csv`](translation_review.csv)（Excel・Googleスプレッドシートで開ける。1 行 = 1 つの文言、列 = 言語）。**確認する人には、言語ごとの確認シートを渡す**: `dart run tool/export_review_packets.dart build/native_review pl`（言語タグを省略すると全言語）。`review_<言語>.csv`（key・まとまり・日本語・English・この言語・長さ・残すもの・直した文言・理由。最後の 2 列は書いてもらう欄）と、`numbers_<言語>.tsv`（数の読み上げの境目の数）が出る。「長さ」は日本語に対する文字数の比（折り返しの目安）、「残すもの」は訳に残すプレースホルダ。
2. 確認の観点（下の「全言語共通」と、言語ごとの「重点」）で見て、直したい文言は「キー・今の文言・直した文言・理由」の 4 つで返してもらう。
3. 返ってきた直しは `lib/src/l10n/strings.dart` に反映し、`dart run tool/export_strings.dart` で一覧を更新する（更新を忘れるとテストが失敗する）。
4. 数の読み上げ（保護者ゲート）は、`dart run tool/dump_numbers.dart <ロケール>` で出した一覧を別に渡して確認してもらう（下の「数の読み上げ」参照）。

## 全言語共通の観点
- **子どもに向けた自然な口調か**。責めない言い方か（「間違えた」より「もう一度やってみよう」）。丁寧すぎ・くだけすぎがないか。
- **口調の統一**（です・ます／敬称／二人称）。画面全体で混ざっていないか。
- **性別がはっきりする言い方を避けているか**（男の子・女の子の別が出る形容詞・動詞の活用など）。
- **複数形・数に合わせた形**（1 個／2 個／5 個）が正しいか。
- **小数点・年の書き方**（`1,5` と `1.5`、紀元前・西暦の言い方）。
- **文の長さ**。ボタンやカードに入る短さか（長い言語で折り返して崩れないか）。
- **新しく足した文言**（下の一覧）は、特に念入りに。

## 新しく足した文言のまとまり（キーの接頭辞）
| 接頭辞 | 使う場面 | 見る点 |
|---|---|---|
| `nudge*` | 学習を促す通知 | 責めない・押しつけない。数字を含まない短い文 |
| `myWeek*` | 子ども本人の週のふりかえり | できたことを褒める。学習していない週は「いつでも始められる」と伝える |
| `reason*` | 間違えた理由を選ぶ（わからなかった／忘れていた／うっかり／時間が足りなかった） | 選びやすい短いラベル。「うっかり」の軽さ |
| `break*` | 休憩の提案 | 命令口調にしない。「あてずっぽう」は責めずに「ゆっくり読もう」 |
| `card*` | 暗記カードの自己採点（わからない／あやしい／わかった）とめくる | 3 つの段階の差が伝わる。ボタンに入る短さ |
| `peakAhead` | 問題の多い日が近いときの一言 | 不安をあおらない。「少し先にやっておこう」程度の軽さ。数字を含まない |
| `talk*` | **保護者**への声かけの提案（伸びた／克服／継続／はじめの一歩／おやすみ） | 保護者に向けた丁寧な口調（子ども向けの口調と区別）。**結果より取り組みをほめる**。他の子や先週と比べない。「おやすみ」は責めない |
| `eveNotice` / `testDayNotice` | テスト前日・当日に子どもへ出す一言 | 落ち着かせる。「新しいことを増やさない」が伝わる。励ましすぎて重圧にならない |
| `report*` / `teacher*` / `sheet*` / `checklist*` | 保護者レポート、先生役、直前プリント、当日チェック | 以前からの文言。まだネイティブ確認は未実施 |
| `deviation*` | アプリ内偏差値の注意書き | 「全国の偏差値ではない」が正確に伝わる |

| ko | 해요체の統一。数の読み上げは漢字語の数詞（일・이・삼…） |

| th | **仏暦（พ.ศ.）に西暦を添える年の表記**。ครับ／ค่ะ の性別表現を避けているか。数詞（`ยี่สิบ`・`เอ็ด`）。単語の間に空白を入れない書き方 |

| ru | **複数形は 3 つ**（1・2〜4・それ以外。11〜14 は「それ以外」）。性別がはっきりする過去形（`справился` など）を避けているか。`ты` の口調 |
| it | 数の読み上げの省略・アクセント（`ventuno`・`ventotto`・`centottanta`・`ventitré`）。`tu` の口調 |
| nl | 数の読み上げ（`eenentwintig`・`tweeëntwintig`）。`je` の口調 |
| pl | **複数形は 3 つ**（1 だけが単数形。21・101 は複数形）。千は 2〜4 が `tysiące`・5 以上が `tysięcy`。性別がはっきりする過去形を避けているか |
| de / de-CH | `du` の口調。スイスは `ß` を使わず `ss`、小数点が `.` |
| zh-Hans / zh-Hant | 簡体と繁体で用語が合っているか（台湾・香港でも通じるか）。「会了」「不会」などの口語 |

## 数の読み上げ（保護者ゲート）
保護者ゲートは「画面に出た数を言葉で読んだ文」を見て、数字で入力する方式。読み上げの文が不自然だと、保護者が混乱する。1〜9999 が正しい言葉で出ているかを確認してもらう。
- 一覧は `dart run tool/dump_numbers.dart <ロケール> [最小] [最大]` で出せる（例: `dart run tool/dump_numbers.dart pl 1 100 > numbers_pl.tsv`。出力は「数」と「読み」をタブで区切った 2 列で、スプレッドシートに貼れる）。既定は 1〜9999。
- すべてを見る必要は無い。**境界の数**（1・10・11・12・13・19・20・21・99・100・101・110・111・999・1000・1001・1100・1999・2000・9999）と、その言語で綴りが変わりやすい数（上の表の言語ごとの重点）を中心に。

## 実機のフォント確認（画面・成長カード・直前プリント）
文字が四角（□）になる、字体が崩れる、行が重なる、といった問題は、端末とフォントによる。次を実機（Android・iOS）で見る。
| 文字 | 確認する場所 | 備考 |
|---|---|---|
| 日本語・中国語（簡体・繁体）・韓国語 | 成長カード、年表、直前プリント | CJK の字体が混ざらないか。成長カードの画像化では `fontFamilyFallback` を渡す |
| タイ語・ヒンディー語（デーヴァナーガリー） | 成長カード、画面全体 | 結合文字・行の高さ。端末のフォントが要る |
| アラビア語 | 画面全体（右から左）、成長カード、直前プリント（`dir="rtl"`） | 接続形の表示、数字や英字が混ざった文の並び、成長カードの左右反転（バッジが左） |
| キリル文字（ロシア語）・ラテン文字（その他） | 全体 | ダイアクリティカルマーク（ł・ą・ë・é・ü など）が出るか |
