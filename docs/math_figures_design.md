# 図・グラフ・データの扱い（数学の図形／空間図形／データの活用）の設計

> ステータス: データ（C）・π・平面図形（A）・空間図形（B）・作図（体験型）・図が選択肢の問題は実装済み。`docs/math_foundation.md` の続き。中1数学の未着手の3分野（平面図形・空間図形・データの活用、計 約 140 問ぶん）を、変種生成（`MathTemplate`）と同じ「型から機械で作る」方式で扱うための方針。先に決めたいことは §8。

## 1. 目的と前提
- 図が要る問題でも、**数だけ変えた変種を機械で作り、答えは式から計算する**。図を 1 枚ずつ描いて持つと、容量（社会・理科より先に数学が重くなる）と作成の手間が増え、答えと図の食い違いも起きる。
- 図は**データ（座標・長さ・角度・ラベル）で持ち、描くのは画面側**。基盤が持つのは、図の仕様・値の計算・検証・文字での説明まで。
- 図を見ないと解けない問題を作るので、**文字での説明（読み上げ・色覚）も同じデータから作る**。

## 2. 3つの系統
| 系統 | 単元 | 図の持ち方 |
|---|---|---|
| A. 平面図形 | 直線・角・円・作図、移動、おうぎ形 | 宣言的な図の仕様 `FigureSpec`（点・線分・円・弧・角印・ラベル）。数は `{a}` で差し込む |
| B. 空間図形 | 立体、表面積・体積 | 立体の種類とサイズ（`solid: cylinder, r, h`）。画面側が決まった斜投影で描く。展開図も同じ仕様から |
| C. データ | ヒストグラム、相対度数、代表値 | 数列そのもの（データ）。表・ヒストグラム・度数分布は画面側がデータから描く |

## 3. 図の仕様 `FigureTemplate`（平面図形は実装済み）
型（`templates.json`）に `figure` を足す。座標は数か式（`"10+80*b/(a+b)"`。パラメータ・`stats`・`derived` の名前が使える）、ラベルは `{…}` を差し込む。

```json
"figure": {
  "viewBox": [0, 0, 100, 80],
  "points": {"A": [10, 70], "B": [90, 70], "C": ["10+80*b/(a+b)", 12]},
  "draw": [{"poly": ["A", "B", "C"]}],
  "marks": [{"angle": ["B", "A", "C"], "label": "{a}°"}, {"angle": ["A", "C", "B"], "label": "x°"}],
  "names": true, "altId": "fig_triangle_two_angles"
}
```
- 点: `[x, y]` か `{"polar": [中心の点, 半径, 角度（度）]}`（先に宣言した点が中心。角度は反時計回り、y は下向き）。**図は縮尺が厳密でなくてよい**（教科書の図と同じ。角の大きさは極端に食い違わない程度）。角度が正確に要る図（対頂角・おうぎ形）は `polar` で作る。三角関数は式に入れない。
- `draw`: `seg`（線分）・`poly`（多角形。`fill`）・`circle`（`[中心, 半径]`）・`arc`（`[中心, 半径, 開始角, 終了角]`）。`style: dashed` で破線。
- `marks`: `angle`（`[端, 頂点, 端]`＋`label`。小さい側の角に弧と文字）・`right`（直角印）・`tick`（等しい辺の印。`n` は 1〜4）・`length`（`[点, 点]`＋`label`。線分の横に文字）・`text`（`[点, 文字列]`）。`names: true` で点の名前を図の外側向きに添える。
- `altId`: 図の説明文の ID（文言はコンテンツ側）。図に出る数値は `display` と同じ値から作る。
- **描けない引き方（点が枠の外・点の重なり・一直線の角・半径 0・NaN）は、その種を引き直す**（`Variant.figure` は常に描ける図）。毎回描けなければ `template_unsatisfiable`。書き間違い（未知のキー・宣言のない点・式の文字）は型の読み込みで `FormatException`。

### 関数のグラフの図 `figure.plot`（実装済み）
```json
"figure": {"plot": {"x": [-4, 4], "y": [-3, 30], "curves": [{"expr": "a*x^2"}],
                    "points": [{"at": ["p", "q"], "label": "A({p}, {q})"}], "ticks": {"x": 1, "y": 5}}, "altId": "fig_parabola_point"}
```
- 点・描画・印・立体とは併用しない（枠は 100 × 100）。`x`・`y` は範囲（数か式。**0 を含むこと**）で、枠の内側（10〜90）に収める（縦横の縮尺は範囲で決まる）。
- `curves`（1〜4 本）: 式 y = f(x)（`x` とパラメータ）を 80 分割の折れ線で描く。y の範囲で切り取り、NaN・無限大の点で途切れる（`1/x` は左右 2 本）。`dashed` で破線。
- `points`（8 個まで）: 点（小さな円）とラベル（右の枝は右下、左の枝は左下に置いて曲線をよける）。範囲の外の点は描けない（引き直し）。
- `ticks`: 軸の目盛り（間隔。0 は除く。13 本を超えると省き、細かすぎる（範囲の 48 倍超）と描けない）。
- 描けない図（範囲が 0 を含まない・点が範囲の外ほか）は引き直す。形は `FigureShapeKind.polyline`（開いた折れ線）で、SVG は `<polyline>`。
- 見本: `docs/content_drafts/suugaku_chu3/templates.json`（`m3_fn_graph_001`）。

### 動く図 `figure.animation`（実装済み）
時間 `t` で変わる図（ボールの落下、点が曲線の上を動く、図形が広がる）。どの図（点・線・`plot`・`solid`）にも付けられる。
```json
"figure": {"plot": {"x": [0, 6], "y": [0, 200], "curves": [{"expr": "5*x^2"}], "points": [{"at": ["t", "5*t*t"]}]},
           "altId": "fig_free_fall_motion",
           "animation": {"from": 0, "to": "p", "frames": 13, "durationMs": 2600, "loop": false}}
```
- `from`・`to`: 時間の範囲（数かパラメータの式。`to` が `from` より小さくてもよい=逆再生）。`frames` は 2〜120（既定 24）、`durationMs` は 200〜20000（既定 3000）、`loop`（既定 偽）。図の式では `t` が使える（パラメータ名に `t` は使えない）。
- 変種の `Variant.animation`（`FigureAnimation`）に全コマの図 `frames`・時刻 `times`・`durationMs`・`loop`。`Variant.figure`（静止画）は最後のコマ。`indexAt(進み具合 0〜1)`・`figureAt`・`toSvgFrames()`。**再生は画面側**（タイマーでコマを切り替える。基盤はコマの作り方と検証だけ）。
- どれかのコマが描けなければ（枠の外・点の重なりほか）、その変種は引き直す（毎回なら `template_unsatisfiable`）。`from == to` は動かないので描けない。
- 容量はほぼ増えない（コマは式から作る。ファイルに持たない）。
- 見本: `docs/content_drafts/suugaku_chu3/templates.json` の `m3_fn_use_002`（落下距離 y=5t²。点が p 秒まで動く）。

## 4. 描画（実装済み）
- **core が SVG 文字列を作る**: `Figure.toSvg({fontSize, padding})`（純粋な Dart）。画面（Flutter）は SVG を描画する部品で表示するか、`Figure.shapes`・`labels` から自前で描く。検証ツールが全変種を SVG に落として目視・差分確認でき、成長カードなどの共有にも使え、Web でもそのまま使える。
- 色は `currentColor` だけ（画面の文字色・ダークモードに合わせる）。ラベルは XML エスケープ。枠の外側に余白をとり、端の点の名前が切れない。
- ラベルの文字は、言語とフォントが画面側のもの（SVG の `text` 要素）。

## 5. 系統ごとの設計
### A. 平面図形
- 角度の問題: 三角形の内角の和、対頂角、平行線と角（図は座標から計算）。答えは式で計算（`{180-a-b}`）、誤答は「外角と取り違え」「和を 360 と思う」などを `wrong` に。
- 作図: 問題としては選択式（手順の並べ替え `order` タイプ）。**実際に描かせる作図は体験型**（`Exploration` に種類 `construction` を足す案。コンパスと定規の操作は画面側）。
- 移動: 「図形 F を、平行移動／回転／対称移動したあとの座標」。座標は数値の変換で計算（式で書ける）。誤答は「回転の向きの取り違え」「x と y の入れ替え」。
- おうぎ形: 弧の長さ・面積。**答えに π を使う**（§6）。

### B. 空間図形（実装済み）
型の `figure` に `solid` を書く（点・描画・印とは併用しない。枠は 100 × 100 に固定）。

```json
"figure": {"solid": {"kind": "cylinder", "dims": {"r": "r", "h": "h"}, "labels": {"r": "{r}cm", "h": "{h}cm"}}, "altId": "fig_cylinder"}
```
- `kind`（`view` は省略すると立体）: **立体** `prism`・`pyramid`（n=底面の辺の数 3〜8・r=底面の外接円の半径・h=高さ。底面は縦を 0.3 に縮めた楕円に内接する正 n 角形で、見える辺は実線・見えない辺は破線。n が 4 の倍数のときは半周期ずらして角を手前にする。ラベルは h だけ。n が 3〜8 の整数でなければ描けない=引き直し）・`cuboid`（a・b・c）・`cylinder`（r・h）・`cone`（r・h）・`sphere`（r）、**展開図**（`"view": "net"`）`cube`（a）・`cylinder`（r・h）・`cone`（r・h）。寸法は数か式（`"sqrt(l*l-r*r)"` も可）。
- ラベルに使える名前: 立体は寸法の名前、円柱の展開図は r・h・w（長方形の横＝円周）、円錐の展開図は r・l（母線）、立方体の展開図は a。文字列は `{…}` を差し込む。
- 描き方: **斜投影**（奥行きは右上へ 45°・半分の長さ）。円の面は縦を 0.3 に縮めた楕円（手前の半分は実線、奥の半分と見えない辺・半径・軸は破線）。寸法の比を保ったまま 72 に収め、枠の中央に置く。
- 展開図: 立方体は十字形、円柱は長方形（横が 2πr）の上下に接する円、円錐は中心角 360r/l のおうぎ形（180° を超えても枠に収まる）と、弧の真下に接する底面の円。
- 寸法が正でない・計算できないときは描けない（引き直し）。
- 見本: `docs/content_drafts/suugaku_chu1/templates.json` の `m1_space_fig_*`（円柱・円錐・球の体積と表面積、直方体の体積と表面積）と `m1_space_net_*`（円柱の展開図の横の長さ、円錐の展開図の中心角）。
- 角柱・角錐は、図なしの型（体積、面・辺・頂点の数。`m1_space_prism_001`・`m1_space_pyramid_001`・`m1_space_solid_*`）まで作った。平行線と角は図つき（`m1_geo_parallel_*`）。
- 角柱・角錐の図（`solid` の `prism`・`pyramid`）も作った（`m1_space_solid_*_002〜`・`m1_space_prism_002`・`m1_space_pyramid_002`）。
- まだない: 立体の切断。

### C. データ（実装済み）
- **データを乱数で作る**: パラメータに数列を足した（名前は英大文字 1 字。`"L": {"list": {"n": [7, 11], "int": [1, 30]}}`）。種から決まった個数・値の数列ができる（`Variant.lists`）。
- **集計は `stats`**: 数列から求める値を英小文字 1 字の名前で宣言する（`"stats": {"m": "mean(L)", "d": "median(L)", "f": "count(L, p, q)"}`）。関数は `sum`・`mean`・`median`（偶数個は中央 2 つの平均）・`mode`（最頻値が複数なら引き直す）・`range`・`min`・`max`・`count`（`count(L)` は個数、`count(L, lo, hi)` は lo 以上 hi 未満の度数）。引数の lo・hi は数かスカラーのパラメータ名。求めた値は `derived`・`constraints`・`display`・`answer`・`wrong` の式で使える。
- 表示: `{L}`（そのままの順）、`{~L}`（小さい順）で `3, 8, 5` のように差し込む。表・ヒストグラムは画面側が `Variant.lists` から描く（階級の幅は型のパラメータ）。
- 見本: `docs/content_drafts/suugaku_chu1/templates.json` の平均・中央値・最頻値・範囲・度数・相対度数（`m1_data_*`）。誤答の型: 平均と中央値の取り違え、最大値を範囲と答える、度数と相対度数の取り違えなど。
- 数列の中で述語（「中央値が整数」など）を `constraints` に書く案は、必要になったら足す（今は引き直しで足りている）。

## 5.5 選択肢が図の問題（実装済み）
型の `choice` で、**選択肢の ID ごとに図**をつける。`choices` は `{…}` を含めない ID（画面は ID の位置に図を出し、ア・イ・ウ…はその並びで付ける）。

```json
"type": "choice", "choices": ["ok", "n1", "n2", "n3"], "answer": "ok",
"figures": {
  "ok": {"pick": {"index": "a", "of": [図, 図, …]}},
  "n1": {"pick": {"index": "b", "of": [図, 図, …]}},
  …
},
"wrong": [{"expr": "n1", "tag": "not_a_cube_net"}, …]
```
- 図は `figure` と同じ書式（平面図形・`solid`）。`pick`（`index` の式の値で `of` の中から 1 つ）を使うと、種ごとに別の図が出る。添字が整数でない・範囲外・図が描けないときは、その種を引き直す。変種の `Variant.choiceFigures`（ID → `Figure`）を画面が選択肢に描く。選択肢の並びは種で決まる。
- 立方体の展開図 `net/cells`: `{"solid": {"kind": "cells", "view": "net", "cells": [[列, 行], …]}}`。マスの正方形を並べる（1 マスは最大 18、全体は 72 に収まる）。`isCubeNet(cells)` が、立方体の展開図になるか（6 マス・辺でつながる・折りたたむと 6 面がそろう）を、**立方体を展開図の上で転がして**判定する。35 種類の六マスのうち 11 種類が展開図。
- 検証 `template_net_mismatch`: 選択肢が全部 `net/cells` の型で、**正解の選択肢だけが立方体の展開図になる**ことを全種で確かめる。展開図が 0 個・2 個以上・正解以外が展開図、はエラー。
- 見本: `docs/content_drafts/suugaku_chu1/templates.json` の `m1_space_netchoice_001`（展開図選び。展開図 11 種・そうでない 8 種から種ごとに選ぶ）、`m1_space_solidchoice_001/002`（円柱・円錐の見取り図選び）、`m1_func_graphchoice_001`（比例のグラフ選び）。

## 6. 円周率 π（実装済み）
- 式に **`π`（または `pi`）を円周率の定数**として書ける。`12π`・`3/2π`・`3π/2`・`r^2π` のように省略した掛け算にも使える。変数 `p` と `i` の積は `p*i` と書く（`pi` は円周率になる）。
- 同値判定は数値で行う。`12π` と、十分に長い小数 `37.699111843077517` は同じ値。**`3.14` を使った近似 `37.68` は別の答え**（「π で答えなさい」の問題では誤り、近似値で答える問題では近似値を正解に書く）。
- **形 `in_terms_of_pi`**: π を 1 つ含む、整数どうしの積・商（`12π`・`3/2π`・`3π/2`・`-π`）。小数や π のない答え（`37.68`）、`π+1`・`π*π`・`2π+3π`・`12/π` は不可。約分されているかは見ない。値が合っても形が違えば `wrongForm`。
- 型の書式 **`{$e}`** は、係数 `e` に π を付けて出す（`12π`・`3/2π`・`π`・`-π`・`0`）。`{+$e}` で符号つき、`{&$e}` で負のときかっこつき。
- 見本: `docs/content_drafts/suugaku_chu1/templates.json` の円周・円の面積・おうぎ形の弧と面積・円柱の体積と表面積・円錐・球（`m1_geo_*`・`m1_space_vol_*`）。誤答の型: 半径と直径、周と面積、錐体の 1/3 忘れ、球の体積と表面積の取り違えなど。

## 7. 実装の順
1. データ（C）: 数列パラメータ、集計（`stats`）、表示 `{L}`、誤答の型。**実装済み**。
2. π の定数と `in_terms_of_pi` の形（おうぎ形・円柱・円錐・球の計算問題が、図なしで型にできるようになる）。**実装済み**。
3. 平面図形（A）: `FigureTemplate` の読み込み・検証・`Figure.toSvg`（点・線分・円・弧・角印・直角印・等しい辺の印・長さ・ラベル）。**実装済み**（見本: 三角形の内角・対頂角・隣り合う角・二等辺三角形・おうぎ形）。
4. 空間図形（B）: 立体の斜投影と展開図。**実装済み**（直方体・円柱・円錐・球、立方体・円柱・円錐の展開図）。
5. 体験型の `construction`（作図）は**実装済み**（`docs/math_foundation.md` §9）。図が選択肢の問題は未実装。

## 8. 先に決めたいこと
1. **core が SVG を作る**（案）か、仕様だけ持って画面側が描くか。案: 作る（検証・共有・Web に有利。コード量は増える）。
2. **着手順**: データ → π → 平面図形 → 空間図形（案）。図が不要な部分から先にやり、図の描画は後ろに回す。
3. **π の扱い**: 記号 `π` を定数にし、「π を使って答える」問題と近似値の問題を分ける（案）。
4. **作図は問題ではなく体験型**にする（案）。評価（○×）が作りにくいので、完成した図が正しい構成かを判定する関数を `Exploration` に足す形。
5. **図の選択肢の問題は後回し**（案）。

## 9. やらないこと
- 手描き・写真の図（容量と著作権の管理が重い。必要なら教科書準拠でなく自作）。
- 図からの自動採点（子どもが描いた図の画像認識）。
- 3D の自由回転（斜投影の固定表示のみ）。
