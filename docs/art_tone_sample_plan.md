# 絵のトーン（B: ゆるかわ・落ち着いた）の見本づくりと確認の手順

> ステータス: 手順の案（2026-11-02）。トーンは B に決定済み（[`world_design.md`](world_design.md) §6）。ここは「B が幼すぎず冷たすぎないか」を見本で確かめる手順。**結果を見る前に基準を決める**（[`design_principles.md`](design_principles.md) §2-6）。

## 1. 作る見本（5 枚）
| # | 内容 | 見るところ |
|---|---|---|
| 1 | 相棒（数学）の中1 の姿と、中3 の姿（同じキャラを並べる） | 学年で大人っぽくなる向き。同じキャラに見えるか |
| 2 | 基地（ホーム）の画面。相棒・図鑑の入口・今日の勉強 | 余白、文字の読みやすさ、幼さ |
| 3 | 数学・中1 の部屋（ゲット後。工房の 1 階） | 世界観（工房）、実例の小ネタ、キャラの小物 |
| 4 | 図鑑（ゲット済み 3 匹・シルエット 4 匹・「あと N 単元」） | 「集める」寄りになりすぎていないか |
| 5 | スタンプ 8 枚（1 キャラ） | 友だちに送れる雰囲気か |
- 参考として、同じ 1 と 2 を **A（かわいい）・C（クール）** でも 1 枚ずつ描き、並べて見比べる（B が中間にあるかを確かめる）。
- 守る: 個人の情報（名前・点数）を絵に入れない。実在の人物・企業のキャラに似せない。キラキラした演出を使わない。

## 2. 制作の指定（絵を描く人へ）
- 線は細めでシンプル、色はくすませる。キャラは小さめ。余白をとる。
- 教科の世界の基調色: 数学=暖色（工房）／英語=青（港）／社会=茶（地図）／理科=緑（自然）／国語=深い色（図書館）。
- 色は `docs/accessibility_colors.md`（コントラスト・色覚の配慮）に合わせる。ダークモード版も 1 枚。
- 動きのある演出（進化など）は、静止画でも意味が通じるように。動きを減らす設定の版も想定する。

## 3. 確認のしかた
- 見てもらう人: 中学生の保護者（5〜10 人）、可能なら本人（保護者の同意のもと。学年を分ける）。個人情報は集めない（年代・学年だけ）。
- 聞くこと（5 問、5 段階＋ひとこと）:
  1. 友だちに見られても恥ずかしくないか。
  2. 幼く感じるか。
  3. 冷たく・暗く感じるか。
  4. 勉強したくなる雰囲気か。
  5. 中1 と 中3 で、成長の違いが伝わるか。
- **基準（結果を見る前に決める）**: 1 は「恥ずかしくない」が多数、2 と 3 はどちらも「感じる」が半数未満、5 は「伝わる」が多数。満たさなければ、満たさない項目を直して再確認する。基準を変えるときは理由と日付を記録する。
- A と C との見比べ: B が A より「幼くない」、C より「冷たくない」と選ばれるかを見る。

## 4. 進め方
1. 絵を描く人を決める（運営者）。見本 5 枚＋比較 2 枚の制作。
2. 確認（上の 5 問）。結果をこの文書に追記する（日付つき）。
3. 基準を満たしたら、トーンの指定（線の太さ・色・頭身）を `world_design.md` §6 に数値で書き足し、国ごとのキャラの絵の基準にする。
