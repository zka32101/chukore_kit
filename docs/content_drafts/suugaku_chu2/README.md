## 前提の流れ
式の計算（多項式 → 単項式 → 利用）→ 連立方程式（解き方 → 利用）→ 一次関数（グラフ → 式 → 二元一次方程式とのつながり → 利用）。平行と合同（平行線と角 → 合同と証明）→ 三角形と四角形（二等辺三角形 → 平行四辺形）。確率（場合の数 → 確率）。データの比較（箱ひげ図）。

## 基盤で足りるもの・足りないもの（型を書く前に確認）
| 分野 | 今ある部品 | 足りないもの |
|---|---|---|
| 式の計算 | 式の同値判定・`form: expanded`・誤答の型（同類項・かっこ） | 多項式どうしの積は中3。指数の計算（単項式の乗除）の誤答の型 |
| 連立方程式 | 式の判定、一次方程式の途中式の判定 | 連立方程式の途中式の判定（`checkSolutionSteps` は 1 本の方程式）。当面は「x の値」「y の値」を別の問題にする |
| 一次関数 | 座標・図（線分・点）、スライダーの体験（`ex_linear_ab`） | 直線のグラフを式から描く図（`Figure` は点と線分で書ける）、2 直線の交点 |
| 平行と合同・三角形と四角形 | 角の図（`figure`）、`order`・`choice` | **証明**の問題（根拠の穴埋め・手順の並べ替え。当面は `order`・`choice`）、合同条件の図 |
| 確率 | `form: reduced_fraction`、場合の数は数値 | 樹形図の図 |
| データの比較 | 代表値（`stats`）、`ChartSpec` | **箱ひげ図**（`ChartKind` に追加が要る）、四分位数の計算（`stats` に追加） |
