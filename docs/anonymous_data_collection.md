# 回答データの匿名集計 設計書（案）

`calibrateDifficulty`（実測難易度）と `analyzeDistractors`（誤答の選択肢の分析）は、**1問あたり数十件以上の回答**が要る。端末1台の履歴では足りないので、アプリが「個人を特定しない回答の束」を集めて渡す。**chukore_kit は集めない・送らない**（このドキュメントは、アプリ側が作るときの仕様の案）。

> ステータス: 案。**法務確認（13歳未満の扱い、各国の個人情報・児童向け規定）と、ストア（Google Play データセーフティ / App Store プライバシー表示）の確認が済むまで実装しない。** 数値は暫定。

## 1. 原則

1. **任意（オプトイン）**。初期値はオフ。保護者の同意（13歳未満は必須）。いつでもオフにでき、オフにしたら以後は送らない。
2. **送るのは回答の統計だけ**。個人・端末・時間の手がかりになる項目は送らない。
3. **小さいグループは出さない**。少数の回答から個人が推測されないように、集計側で下限を設ける。
4. **学習の機能は、送らなくても全部使える**。送ることを特典や継続の条件にしない。

## 2. 送る項目（回答1件）

| 項目 | 内容 | 備考 |
|---|---|---|
| `questionId` / `questionVersion` | 問題とその版 | 版が違う回答は混ぜない（`BankDiff` の version） |
| `chosenId` | 選んだ選択肢のID | `choice`・`map` のみ。選択式以外は空 |
| `correct` | 正誤 | |
| `mode` | `practice` / `mock` | 難易度補正は練習のみ |
| `hintsUsed` | ヒント使用数 | 1以上は集計から除く（どちらも送る） |
| `ageBand` | 学年（中1〜3）だけ | 任意。年齢や生年月日は送らない |

**送らない**: 名前・メール・ニックネーム・端末ID・広告ID・IPの保存・位置・回答日時（日付も）・所要時間（`elapsedMs`）・回答の順番・自己申告の理由（`reason`）・自信（`confident`）・学習計画・テスト日・成績や偏差値。

- 回答日時を送らないので、**同じ人の回答を結びつけない**。送信ごとに新しいランダムな束ID（その束の中だけで使う）を付けて、端末に残さない。
- 所要時間は難易度の補助になるが、送ると端末の癖が出る。必要になったら、問題ごとの中央値（端末内で計算）だけを別項目として検討する。

## 3. 送り方

- **束にして送る**（1回に最大500件など）。Wi-Fi・充電中・アプリを開いたときに、1日1回まで。
- 送る前に、**画面で「何を送るか」を見せる**（項目の一覧と件数。回答の中身は見せなくてよい）。
- 通信は TLS。サーバーは**IPアドレスを保存しない**（ログからも除く）。
- 送れなかった束は捨ててよい（再送の仕組みを作らない＝端末側に残さない）。

## 4. 集計側（サーバー）

- 問題 × 版 ごとに、選択肢の選択回数だけを保持する。**個々の回答は保存しない**（受け取ったらすぐ加算して捨てる）。
- 公開・参照できるのは、**1問あたり 30 件以上**（`analyzeDistractors` の `minAttempts` と同じ）になってから。それ未満は誰にも見せない。
- 出力は `Attempt` の束に戻すのではなく、**問題ごとの選択肢別の回数表**にして渡す。→ 必要なら `analyzeDistractors` / `calibrateDifficulty` に、回数表から合成した回答を渡す変換を、基盤に足す（個人情報が無いので基盤に置ける）。
- 保存期間: 回数表は問題の版が上がるまで。生の受信ログは**保存しない**。

## 5. 同意の流れ（案）

1. 設定の中に「みんなの回答から問題をよくする」（既定オフ）。
2. 保護者の画面でだけ有効にできる（`AgePolicyTable` に `ChildFeature.dataSharing` を追加して、既定は**不許可**にする）。
3. 説明は短く: 何を送る／何を送らない／いつでもやめられる／やめても何も変わらない。**18言語の文言を `ChukoreStrings` に足し、ネイティブ確認を受ける**。
4. オンにした日と、同意した版（この文書の版）を端末に保存する。項目が変わったら、再度同意をとる。

## 6. 基盤（chukore_kit）に足せるもの（実装は同意が決まってから）

- `ChildFeature.dataSharing`（既定は不許可）。
- 送る束を作る関数（`Attempt` から上の項目だけを取り出す。日時・所要時間・理由は落とす）。**これが「送らない項目を落とす」ことを、テストで固定する**のが肝。
- 回数表 → 分析関数への入力の変換。
